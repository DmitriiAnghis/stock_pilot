# StockPilot

Семестровый проект по дисциплине «Программирование мобильных приложений» (PAM), ТУМ.
Мобильное приложение для складского учёта на Flutter (Material 3).

## Экраны (L2 — статический UI)
1. Вход / регистрация
2. Каталог товаров
3. Карточка товара
4. Форма складской операции
5. Складские ячейки
6. Карточка ячейки
7. История операций
8. Профиль пользователя

## Запуск
```
flutter pub get
flutter run
```
